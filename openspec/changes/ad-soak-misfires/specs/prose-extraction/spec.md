# Spec Delta

## MODIFIED Requirements

### Requirement: Comment blocks

Line comments of the same style (a `///` run and a `//` run stay separate), each on its own line and on consecutive lines, SHALL merge into one comment block. A divider comment SHALL end the block above it and start a new one below it.

#### Scenario: Consecutive line comments merge
- **WHEN** three `//` lines sit on consecutive lines with no code between them
- **THEN** the rules see one comment block spanning the three lines

#### Scenario: Divider splits a run
- **WHEN** a `// --- Setup ---` line sits between two consecutive `//` lines of prose
- **THEN** the rules see two one-line comment blocks and no divider text

### Requirement: Comments that are never prose

The following SHALL NOT be prose: a shebang line, a comment whose text starts with `SPDX-License-Identifier` or `Copyright`, a divider comment (a non-doc line comment whose text opens with a run of three or more `-`, `=`, `*` or `~`, alone or around a label: `--- Setup ---`, `==== Phone URL`; doc comments and docstrings never hold dividers, so a `### Errors` heading or a `---` rule inside one stays put) and a tool directive comment matching a built-in pattern (`eslint-`, `@ts-`, `swiftlint:`, `noqa`, `type: ignore`, `shellcheck`, `prettier-ignore`, `biome-ignore`, `rustfmt:`, `#region`, `#endregion`) or a pattern from the ruleset's `comment_directives`. A file whose first five lines contain `@generated` or `DO NOT EDIT` SHALL yield no prose at all.

#### Scenario: Directive is skipped
- **WHEN** a comment reads `eslint-disable-next-line no-console`
- **THEN** it is not prose

#### Scenario: Generated file is skipped
- **WHEN** line 1 of a `.rs` file reads `// @generated by build.rs`
- **THEN** no rule produces a finding for that file

#### Scenario: Divider label is skipped
- **WHEN** a `//` comment reads `--- Load the cache. ---`
- **THEN** it is not prose and counts toward no sentence limit

#### Scenario: Doc comment rule stays prose
- **WHEN** a `///` block above a function holds a `---` line between two paragraphs
- **THEN** the rules see one item-level block
